# Portfolio source assets

All images come from the user-supplied 54-page portfolio. No stock imagery or invented projects.

- Eight named directories: 47 full project pages and original embedded images.
- `archive/`: cover, biography, and repeated chapter indexes (7 pages).
- `identity/`: original cover lettering with alpha, paper texture, and portrait.
- `manifest.json`: source PDF SHA-256, page paths, image xrefs, dimensions, and extracted text.
- `lv-bao-er-portfolio.pdf`: the original source, available to download.

Full pages: 3200px WebP, quality 94, complete uncropped composition. Thumbnails: 960px WebP. Original embedded images retain their native compressed bytes where possible; soft masks are combined into lossless PNGs to preserve transparency. No color grading is applied.

See `docs/pdf-content-audit.md` for the complete page-to-project map. The source PDF contains still frames and QR codes, not embedded video files.
